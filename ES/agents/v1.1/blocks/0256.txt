' Flujo principal
User --> UI : pregunta
UI --> NdjsonClient : envia mensaje
NdjsonClient --> NDJSON : educational POST /api/agent/stream
NDJSON --> Loop : invoca run()

Loop --> SC : delega stream
SC <|.. PAnthropic
SC <|.. POAI
SC <|.. PAzure
PAnthropic --> LLMA : HTTPS
POAI --> LLMO : local HTTP or remote HTTPS
PAzure --> LLMAz : HTTPS

Loop --> Registry : pide schemas
Loop --> Orchestrator : pide tool_use
Orchestrator --> Executor : ejecuta en stream
Executor --> Registry : resuelve handler

' Memoria
Loop --> Msgs : append
Loop --> Cache : marca frontera
Loop --> Compact : umbral tokens
Compact --> Snap : antes de compactar
Loop --> PersistMem : /memory write

' Control y seguridad
Executor --> Perm : ask(toolName,input)
Perm --> BashCls : si es Bash
Executor --> Hooks : PreToolUse / PostToolUse
Hooks --> Guard : tripwires
Loop --> Plan : modo plan
A2A --> SubAgent : audita handoffs
MCPG --> MCP : audita llamadas

' MCP y plugins
Executor --> MCP : invoke tool MCP
MCP --> MStdio : transporte local
MCP --> MSSE : transporte remoto
MCP --> MHTTP : transporte HTTP
Registry <-- PluginSDK : registra tools
Registry <-- Slash : registra comandos

' Sandbox
Executor --> Shell : Bash sandboxed
Shell --> VmSpawn : si vm-mode
VmSpawn --> VmBundle : bundle activo

' Equipo de agentes
Loop --> SubAgent : task / agent tool
SubAgent --> Spawn : limpio
SubAgent --> Fork : contexto copiado; cache contingente
SubAgent --> InProc : in-process
SubAgent --> Handoff : transferencia
SubAgent --> Swarm : multi-agente
SubAgent --> Tasks : background tasks

' Observabilidad
Loop --> NDJSON : eventos
Executor --> NDJSON : eventos
Loop --> Telem : spans
PAnthropic --> Cost : usage
POAI --> Cost : usage
PAzure --> Cost : usage
Loop --> Rate : check budget
Hooks --> Audit : decisiones
Perm --> Audit : decisiones
Audit --> AuditSync : replica
Audit --> AuditHtml : exporta

note right of Loop
  StreamCallbacks normalizes selected events.
  Provider capabilities and errors remain distinct.
  Arrows describe the nominal historical case.
end note

note bottom of NDJSON
  Eventos: message_delta,
  tool_use_delta, tool_result,

note left of PersistMem
  MemoryManager describes persistent memory.
  Retention and access depend on the backend.

end note
