# Ejemplo histórico de configuración global del autor

## Preferencias universales
- Idioma: español de España
- Zona horaria: Europe/Madrid
- Formato de fechas: DD/MM/AAAA
- Formato de números: europeo (punto para miles, coma para decimales)
- Cuando escribas para mí, usa un tono profesional pero cercano

## Seguridad global
- Nunca ejecutes comandos destructivos sin confirmación
- Nunca envíes datos fuera del sistema local sin mi autorización
- Si detectas datos personales en un fichero, avísame antes de procesarlos

Estas preferencias conservan la salida en español del autor. Adapta el idioma
a tu flujo y verifica los controles efectivos del cliente y del entorno.
