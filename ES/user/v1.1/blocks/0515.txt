# Proyecto: Sistema de Gestión Documental

## Contexto
Proyecto de 6 meses para implementar un sistema de gestión documental.
Equipo de 3 personas. Fecha de inicio: enero 2025. Fecha prevista de fin: junio 2025.

## Instrucciones para informes
- Los datos están en la carpeta datos/
- Los informes se generan en la carpeta informes/
- El formato de los informes es Markdown
- El tono debe ser profesional pero directo
- Incluir siempre: avance, tareas completadas, tareas pendientes, incidencias y valoración
- Las cifras deben coincidir exactamente con los datos de los CSV
- Los CSV son fixtures históricos de enero de 2025; no acreditan avance actual.
- Fijar período y cierre del informe y comprobar frescura; rechazar fuentes obsoletas.
- No inferir fecha de finalización ni progreso de tareas con campos vacíos.
