4. curl -u admin:admin https://target:47990/api/apps

5. POST /api/apps con cmd malicioso
   -> comando persistido en config
6. El comando se ejecuta como SYSTEM cuando:
   a) Un cliente Moonlight conecta, o
   b) Sunshine reinicia y un cliente esta configurado
