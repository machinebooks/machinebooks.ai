# AI Safety Engineer and the Machine -- Code Examples

> **Model Security, AI Red Teaming, and Responsible Governance**

Code examples from the book **"AI Safety Engineer and the Machine"** by Carlos Perez Gonzalez and Juan C. Montes.
Part of the series **The Professional and the Machine**.

Each file contains didactic code blocks as they appear in the book.

## Structure

Files are organized by chapter (`cap-XX/`) or by path extracted from the source code.
Each file includes a header comment indicating the source chapter.

## Important

These are **code examples from the book**, not a runnable application.

- API keys use placeholders (`<YOUR_API_KEY>`)
- Each file illustrates a pattern and may need dependencies, helpers, and chapter context
- Python 3.11+ with type hints
- Security tools and guardrails patterns applicable to any AI provider
