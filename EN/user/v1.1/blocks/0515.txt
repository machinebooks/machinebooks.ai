# Project: Document Management System

## Context
6-month project to implement a document management system.
Team of 3 people. Start date: January 2025. Expected end date: June 2025.

## Report instructions
- Data is in the datos/ folder
- Reports are generated in the informes/ folder
- Report format is Markdown
- Tone should be professional but direct
- Always include: progress, completed tasks, pending tasks, incidents, and assessment
- Figures must match the CSV data exactly
- The CSVs are historical January 2025 fixtures; they do not establish current progress.
- Set the reporting period and cutoff and check freshness; reject stale sources.
- Do not infer completion date or task progress from empty fields.
