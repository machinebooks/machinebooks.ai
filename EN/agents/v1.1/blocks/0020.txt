state ToolUseDeclared : id, name known\narguments = ""\nmap event.index to toolIndex\ncallbacks.onToolCall(idx, id, name, "")

ToolUseDeclared --> ReceivingArgs : content_block_delta\ntype = input_json_delta

state ReceivingArgs : arguments += partial_json\ncallbacks.onToolCall(idx, id, name, partial_json)\n\nJSON can be invalid\nuntil the final delta

ReceivingArgs --> ReceivingArgs : next input_json_delta

ReceivingArgs --> BlockClosed : content_block_stop

state BlockClosed : JSON.parse(arguments)\ncallbacks.onToolCallDone(idx)\n\nThe host validates and authorizes\nbefore executing the tool

BlockClosed --> WaitingForBlock : next stream block
BlockClosed --> [*] : message_stop
