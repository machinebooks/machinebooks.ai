' Main flow
User --> UI : question
UI --> NdjsonClient : sends message
NdjsonClient --> NDJSON : educational POST /api/agent/stream
NDJSON --> Loop : invokes run()

Loop --> SC : delegates stream
SC <|.. PAnthropic
SC <|.. POAI
SC <|.. PAzure
PAnthropic --> LLMA : HTTPS
POAI --> LLMO : local HTTP or remote HTTPS
PAzure --> LLMAz : HTTPS

Loop --> Registry : requests schemas
Loop --> Orchestrator : requests tool_use
Orchestrator --> Executor : executes during stream
Executor --> Registry : resolves handler

' Memory
Loop --> Msgs : append
Loop --> Cache : marks boundary
Loop --> Compact : token threshold
Compact --> Snap : before compaction
Loop --> PersistMem : /memory write

' Control and security
Executor --> Perm : ask(toolName,input)
Perm --> BashCls : if Bash
Executor --> Hooks : PreToolUse / PostToolUse
Hooks --> Guard : tripwires
Loop --> Plan : plan mode
A2A --> SubAgent : audits handoffs
MCPG --> MCP : audits calls

' MCP and plugins
Executor --> MCP : invoke tool MCP
MCP --> MStdio : local transport
MCP --> MSSE : remote transport
MCP --> MHTTP : HTTP transport
Registry <-- PluginSDK : registers tools
Registry <-- Slash : registers commands

' Sandbox
Executor --> Shell : Bash sandboxed
Shell --> VmSpawn : if vm-mode
VmSpawn --> VmBundle : active bundle

' Agent team
Loop --> SubAgent : task / agent tool
SubAgent --> Spawn : clean
SubAgent --> Fork : copied context; contingent cache
SubAgent --> InProc : in-process
SubAgent --> Handoff : transfer
SubAgent --> Swarm : multi-agent
SubAgent --> Tasks : background tasks

' Observability
Loop --> NDJSON : events
Executor --> NDJSON : events
Loop --> Telem : spans
PAnthropic --> Cost : usage
POAI --> Cost : usage
PAzure --> Cost : usage
Loop --> Rate : check budget
Hooks --> Audit : decisions
Perm --> Audit : decisions
Audit --> AuditSync : replicates
Audit --> AuditHtml : exports

note right of Loop
  StreamCallbacks normalizes selected events.
  Provider capabilities and errors remain distinct.
  Arrows describe the nominal historical case.
end note

note bottom of NDJSON
  Events: message_delta,
  tool_use_delta, tool_result,
  thinking_delta, permission_request,
  finish_reason, cost_update.
end note

note left of PersistMem
  MemoryManager describes persistent memory.
  Retention and access depend on the backend.
  MemoryStore and autoDream are proposals.
end note
