Attack Vector (AV): Local (L) — requires access to local filesystem
Attack Complexity (AC): Low (L) — no special conditions required
Privileges Required (PR): Low (L) — any user can write
                                      to %LOCALAPPDATA%
User Interaction (UI): Required (R) — the user must start Discord
Scope (S): Unchanged (U) — impact limited to the user context
Confidentiality (C): High (H) — full access to session tokens
Integrity (I): High (H) — arbitrary code execution
Availability (A): Low (L) — the app keeps running

Score: 6.8 (Medium)
Vector: CVSS:3.1/AV:L/AC:L/PR:L/UI:R/S:U/C:H/I:H/A:L
"""

# NOTE: Claude initially computed PR:N (None),
