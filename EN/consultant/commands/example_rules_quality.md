# .claude/rules/deliverable-quality.md

## Quality rules for consulting deliverables

### Mandatory in every deliverable
- Include "Limitations and assumptions" section (minimum 3 points)
- Include generation date and document version
- Include confidentiality classification (Public / Internal / Restricted)
- Do not include client names -- use "the entity" or "the agency"
- Do not include financial data without scaling (factor 0.7-1.3)

### Mandatory in audit reports
- Every finding must have: description, evidence, risk, recommendation, priority
- Priorities use scale: Critical / High / Medium / Low
- Do not use binary "compliant/non-compliant" -- always include nuance and context
- Reference the exact regulatory control (e.g.: "A.8.1 of ISO 27001:2022")

### Mandatory in technical proposals
- Every effort estimate must include a range (minimum-expected-maximum)
- Every professional profile must include relevant certifications
- The differentiator section must contain at least one quantitative data point
- Do not use superlatives without supporting data ("the best" -> "52% win rate")
