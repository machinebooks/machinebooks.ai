# CLAUDE.md -- Technology Consulting Practice

## Practice context
Technology consulting specialized in:
- Information security (ISO 27001, ENS, NIS2, DORA)
- Systems architecture and cloud
- AI adoption and model governance (ISO 42001, AI Act)
- FinOps and cloud cost optimization

Team: 8 consultants (4 senior, 3 semi-senior, 1 junior).
Clients: public sector (60%), financial (25%), industrial (15%).

## Deliverable standards
- Audit report: finding -> evidence -> risk -> recommendation -> priority
- Gap analysis: control -> status -> gap -> action -> owner -> deadline
- Technical proposal: context -> approach -> team -> plan -> estimate -> differentiator
- Every deliverable includes an explicit limitations and assumptions section

## Constraints (CRITICAL)
- NEVER mention client names in intermediate documents
- NEVER include financial data without anonymizing (scale with factor 0.7-1.3)
- Use "the entity" or "the agency" to refer to clients
- Language: technical English, without avoidable jargon
- Voice: direct, data before opinion, limitations before promises

## Reference data
- Average senior consultant hourly cost: EUR95-120 (market range)
- Average ISO 27001 audit duration: 15-25 days depending on scope
- Proposal success rate (win rate): 35-40% market, 52% ours
