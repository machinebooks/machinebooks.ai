# .claude/commands/quick-analysis.md
# Purpose: quick analysis of a client document

Analyze the provided document and generate an executive summary
with structured findings.

## Instructions

1. Read the complete document.
2. Identify: document type, author, date, scope.
3. Extract key points in a maximum of 10 bullets.
4. Flag internal inconsistencies or ambiguities.
5. Cross-reference with relevant regulatory frameworks if applicable.
6. Generate questions the consultant should ask the client.
7. Estimate derived work effort (consultant-hours).

## Format
1-page executive summary + detailed findings + questions.
