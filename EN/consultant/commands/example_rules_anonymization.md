# .claude/rules/anonymization.md

## Anonymization rules (apply ALWAYS)

- NEVER include client, project, or real person names
- NEVER include URLs, IPs, or internal domains
- NEVER include exact contract financial data
- Clients -> "the entity", "the public agency", "the financial sector client"
- Projects -> "the audit project", "the architecture consultancy"
- People -> fictitious names if necessary
- Financial data -> scale with random factor, maintain proportions
